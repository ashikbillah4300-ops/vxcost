# VoxCast

Live megaphone voice broadcaster, audio soundboard mixer, real-time voice changer studio, and always-on-top floating mini-controller for Android.

## Download APK from GitHub

Every push to the default branch (or `v*` tag) automatically builds and publishes installable APKs via GitHub Actions:

1. Open the **Releases** section on the right side of this GitHub repository (or visit `/releases/latest`).
2. Download **`VoxCast.apk`** directly onto your Android device and tap to install.
3. You can also download the build artifacts from the **Actions** tab under **VoxCast-APKs**.

## Features

- **Live Megaphone**: Broadcast your microphone live to loudspeaker, Bluetooth speakers, or wired AUX with Gain Boost, Feedback Guard, PA Horn EQ, Hold-to-Talk mode, and instant PA alert tones.
- **Audio Soundboard**: Upload audio files (MP3, WAV, M4A, AAC, OGG, FLAC) or record voice clips and broadcast them directly through the live microphone audio bus.
- **Real-Time Voice Changer**: Switch live between Natural, Female Voice, Male Voice, Young / Kid, Deep Bass, PA Bullhorn, Cyber Robot, and Custom Studio pitch/formant/echo sliders.
- **Float Over Display**: Draggable always-on-top mini-controller to toggle Live Mic, switch voice presets, and trigger soundboard clips while using other apps.
